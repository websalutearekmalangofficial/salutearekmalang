# Landing Page Sentra Layanan UT

## Ringkasan
Membangun satu halaman utama responsif yang meniru komposisi, warna, dan teks pada gambar referensi, lalu melanjutkannya dengan bagian kelebihan dan testimoni sesuai brief.

## Yang akan dibuat
- Header biru dengan identitas Universitas Terbuka, navigasi, dan tombol masuk/daftar.
- Area utama dua kolom: banner kampus bernuansa biru dan formulir pendaftaran lengkap.
- Alur pendaftaran enam langkah dengan teks Indonesia sesuai referensi.
- Empat kartu kelebihan Salute Arek Malang.
- Tiga testimoni mahasiswa/alumni dengan profil dan badge status.
- Banner kontak WhatsApp di bagian paling bawah.
- Tata letak adaptif: desktop mempertahankan komposisi referensi, sedangkan layar kecil menumpuk konten agar tetap terbaca.

## Detail teknis
- React + Tailwind CSS v4 + Lucide Icons.
- Seluruh warna dan gaya utama memakai token semantik di sistem desain global.
- Form memiliki interaksi isi, pilih jalur, daftar, dan bersihkan data.
- Metadata halaman akan disesuaikan untuk Sentra Layanan UT.
- Gambar unggahan digunakan hanya sebagai referensi desain, bukan ditempel sebagai isi halaman.

## Verifikasi
- Memastikan halaman tampil tanpa error.
- Memeriksa tampilan desktop dan mobile, keterbacaan teks, serta fungsi tombol formulir.
